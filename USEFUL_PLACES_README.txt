USEFUL PLACES

For an image:
type: "image"
image: "useful-places/example.png"
imageWidth / imageHeight
imageOffsetX / imageOffsetY

For text:
type: "text"
name: "Hero Homes"
textOffsetX / textOffsetY
textColor / textSize / textWeight

The coordinate dot remains fixed.

Example text place:
{
  name: "Hero Homes",
  type: "text",
  coordinates: [75.8000000, 30.8500000],
  textOffsetX: 0,
  textOffsetY: -20,
  textColor: "#FFFFFF",
  textSize: 16,
  textWeight: "600"
}
