USEFUL PLACE CONTROLS

Each useful place can independently control:

image
coordinates
imageWidth
imageHeight
imageOffsetX
imageOffsetY

Example:

{
  image: "useful-places/omaxe.png",
  coordinates: [75.7953865, 30.8494569],
  imageWidth: 100,
  imageHeight: 100,
  imageOffsetX: 20,
  imageOffsetY: -10
}

Offset:
+X = right
-X = left
-Y = up
+Y = down

The coordinate dot remains fixed at the exact coordinate.
Only the image moves.

Useful places are independent from the Roads ON/OFF toggle.
