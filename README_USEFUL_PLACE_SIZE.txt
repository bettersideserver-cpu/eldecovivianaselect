USEFUL PLACE IMAGE SIZE

Edit only USEFUL_PLACES in script.js.

Each place:
{
  image: "useful-places/your-image.png",
  coordinates: [LONGITUDE, LATITUDE],
  imageWidth: 80,
  imageHeight: 60
}

The white/blue dot marks the exact coordinate. The image is anchored directly
above it. Every place can have a different imageWidth and imageHeight.

Useful places are independent of the Roads ON/OFF toggle.
