USEFUL PLACE POSITION CONTROLS

Each useful place is anchored to its exact coordinate.

Example:

{
  image: "useful-places/omaxe.png",
  coordinates: [75.7953865, 30.8494569],
  imageWidth: 100,
  imageHeight: 100,
  imageOffsetX: 0,
  imageOffsetY: 0
}

imageWidth/imageHeight = image size.
imageOffsetX = move image left/right.
imageOffsetY = move image up/down.

The coordinate dot NEVER moves when the image size changes.
The marker anchor is the coordinate itself.
